## Entry

UI-001 최초 등록 완료 또는 Wife 전역 Profile Menu의 미연동 전용 `남편 초대` 항목.

## Route

온보딩은 `/onboarding/invite`, 전역 메뉴 재진입은 `/wife/invite`를 사용한다. 실제 공유 URL/Token 형식은 외부 계약 전까지 정하지 않는다.

## Exit

온보딩에서 공유 완료/나중에는 UI-006 Home, 수동 진입에서는 이전 화면.

## Back Behavior

진입 Context에 따라 Exit과 동일하다. 열린 결과 Dialog가 있으면 먼저 닫는다.

## UI State

- Default
- Generating / Sharing

## Interaction

- Tap/Keyboard: 링크 보내기, 나중에, 재시도
- Hover/Focus: CTA와 Text Action
- Transition: 생성/공유 결과 Dialog

## Data

초대 상태, 표시용 초대 Context, 연결 여부, Entry Context, Mock 공유 결과만 정의한다.

Data Source: `MockInvitationService`

Future: 실제 초대 발급 및 OS 공유 Adapter로 교체 예정. 외부 Domain, Token, SMS/카카오 Endpoint를 정하지 않고 Mock을 UI에 하드코딩하지 않는다.

## Responsive

- Mobile-width Web: 20px Padding, Action Full Width
- Tablet-width Web/Desktop: 최대 480px, 중앙 단일 Column

## Accessibility

- Focus: 혜택 → Primary → Later
- Keyboard: 모든 Action 활성화, Dialog Focus Trap/Esc 정책
- Semantics: 생성 중/성공/실패 Live 안내
