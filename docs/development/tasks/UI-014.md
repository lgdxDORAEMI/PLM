## Data

알림 ID, report/request/reminder 유형, 제목/요약/시각, 읽음, 목적 Screen Reference를 정의한다. Raw Route 문자열은 Model에 넣지 않는다.

Future: `ApiNotificationService`와 Push Adapter로 교체. 현재 Push/Backend를 구현하지 않고 Fixture를 UI에 하드코딩하지 않는다.
