## Entry

Bootstrap의 Wife/Profile 완료 Redirect, UI-002 종료, UI-004/005 완료 또는 Wife Shell Home Navigation.

## Route

`/wife/home`을 사용한다. 중앙 Router와 Wife Shell 계약은 구현되어 있으며 실제 Session Guard는 Integration Owner가 연결한다.

## Exit

UI-004/005, UI-007/009/010/011, UI-015/016, Wife Profile Menu로 이동한다.

## Back Behavior

Wife Shell Root 정책을 따른다. Browser Back이 임시 Bootstrap 화면으로 노출되지 않게 한다.

## Required Components

### Reuse

- Foundation 전체 중 필요한 `AppButton`, `AppCard`, `AppBanner`, `AppSkeleton`
- `AppShell`, `AppTopBar`, `AppBottomNavigation`, `ResponsivePageContent`, `CategoryBadge`, `StatusBadge`

### New

- `PregnancyWeekHero`, `RoutineGuideCard`, `RoutineGenerationState`, `DailyCareSection`
- Routine Model/State, `RoutineService`, `MockRoutineService`, Controller, Fixture

## UI Structure

```text
AppShell
├─ AppTopBar(profile menu)
├─ ResponsivePageContent(dashboard)
│  ├─ PregnancyWeekHero
│  ├─ condition not entered: condition CTA only
│  └─ condition entered
│     ├─ RoutineGenerationState
│     └─ DailyCareSection
│        └─ Meal / Household / Health / Sleep cards
└─ Wife Bottom Navigation
```

## UI State

- Loading/bootstrap
- Condition missing
- Generating / Delayed
- Ready / Partial / Complete
- Fallback
- Error / Retrying
- Finish-day Submitting / Disabled

## Interaction

- Tap/Keyboard: Condition CTA, Guide Card, Calendar, Profile Menu, 하루 끝내기
- Hover/Focus: actionable Card/Nav
- Scroll: Hero 다음 Guide 흐름
- Transition: 생성 상태, Route 전환, Reduced Motion

## Data

임신 주차/Tip, 당일 Condition 완료 여부, 4개 Guide Summary, 진행 상태, Fallback 출처를 정의한다.

Data Source: `MockRoutineService`와 최소 공유 Mock Store

Future: `ApiRoutineService`로 교체. LLM/API를 호출하거나 Endpoint/응답 DTO를 UI에 확정하지 않는다. 실패·지연·전일/기본 Fallback을 Mock Scenario로 제공한다.

## Responsive

- Mobile-width Web: 20px, 단일 Column, Hero와 Guide 위계 분리
- Tablet-width Web: 최대 720px, 보조 Summary만 조건부 2열
- Desktop: 중앙 최대 720px, Mobile 화면을 과도하게 늘리지 않음

## Accessibility

- Focus: AppBar → Hero CTA → Guide → Navigation
- Keyboard: Card/Nav/Menu 전체 조작
- Semantics: 임신 주차, 생성/폴백/완료 상태를 Text로 제공
- Tooltip: Icon-only Profile/Nav Action
