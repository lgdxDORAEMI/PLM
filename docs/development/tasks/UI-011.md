## Entry

UI-006 Household Guide Summary.

## Route

`/wife/home/household`을 사용한다. 요청 전송 후 Partner 상세 Route로 직접 이동하지 않는다.

## Exit

요청 전송 결과는 현재 화면 Modal/상태로 돌아오며 Back은 UI-006이다.

## Back Behavior

열린 선택창/Dialog를 먼저 닫고, 미전송 선택이 있으면 확인 후 Home으로 복귀한다.

## UI Structure

```text
Page
├─ AppTopBar
└─ ResponsivePageContent
   ├─ ConditionSummaryBanner
   ├─ 오늘은 이것만 / direct tasks
   ├─ 가전이 대신 / recommendation only
   ├─ 가족과 나누기
   │  └─ HouseholdShareSelector
   └─ RequestStatusView / result Dialog
```

## UI State

- Loading
- Ready / Selected
- Partner unlinked / Disabled
- Submitting
- Success: requested/acknowledged/completed
- Error / Retry
- Empty group

## Interaction

- Tap/Keyboard: Task 완료, 요청 선택/해제, 전송, 재시도
- Hover/Focus: Task/Selection/Action
- Transition: 선택창, 공유 결과와 상태 갱신

## Data

Task 분류, 추천 이유, 완료 상태, Partner 연결 상태, 요청 ID/항목/이유/상태/시각을 정의한다.

Data Source: `MockHouseholdService`와 합의된 공유 Mock Store

Future: `ApiHouseholdService`로 교체. 실제 가전/알림/Backend를 구현하지 않으며 UI에 Fixture를 하드코딩하지 않는다.

## Responsive

- Mobile-width Web: Group 단일 Column, CTA Full Width
- Tablet-width Web/Desktop: 최대 720px, 짧은 보조 Task만 조건부 2열

## Accessibility

- Focus: Context → 3 Group → Request Action → Status
- Keyboard: 복수 선택과 전송
- Semantics: Task 분류, 선택, 요청 상태를 Text로 제공
- 상태 변경을 Live 안내
