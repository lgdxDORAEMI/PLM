## Interaction

- Tap/Keyboard: 환경 선택/해제, 값 수정, 완료
- Input: 문서가 허용한 추천값 조정
- Hover/Focus: 모든 Control
- Scroll: Tip과 환경 설정

## Data

수면 Tip, 출처 Label, 환경 종류/추천값/선택/수정값, 완료 상태만 정의한다.

Data Source: `MockSleepService`

Future: `ApiSleepService`로 교체. ThinQ 명령을 호출하거나 성공한 것처럼 표시하지 않는다. Mock Fixture는 Widget 밖에 둔다.

## Responsive

- Mobile-width Web: 가용 폭에 따라 1열, Text 200%는 항상 1열
- Tablet-width Web/Desktop: 최대 720px, 환경 Card 2열 가능

## Accessibility

- Focus: Tip → 환경 → 값 → CTA
- Keyboard: Selection과 입력
- Semantics: 추천값/사용자값/선택/완료 구분
- 단위를 시각 Label과 접근성 이름에 포함
