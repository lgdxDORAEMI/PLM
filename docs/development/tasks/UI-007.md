## UI State

- Loading/Skeleton
- Ready / Selected period
- Empty recommendation
- Error / Retry
- Accepting / Sharing / Disabled
- Accepted

## Interaction

- Tap/Keyboard: 끼니, 수락/거절, 재추천, 공유
- Hover/Focus: Card Action
- Scroll: 추천과 주의 Section
- Transition: 끼니 변경/수락/공유 결과

## Data

Meal period, 메뉴, 이미지 참조, 추천 근거, 영양 Tag, 주의 항목, 수락/거절/공유 상태만 정의한다.

Data Source: `MockMealService`

Future: `ApiMealService`로 교체. AI/LLM 호출과 공유 Backend를 구현하지 않고 이미지가 없을 때 임의 이미지를 생성하지 않는다. Fixture는 UI 밖에 둔다.

## Responsive

- Mobile-width Web: 단일 Column, Action 필요 시 Stack
- Tablet-width Web: 최대 720px, 끼니 선택 2열 가능
- Desktop: 최대 720px, 이미지 비율과 콘텐츠 폭 유지

## Accessibility

- Focus: Context → 끼니 → 추천 → Actions → 주의
- Keyboard: 모든 선택/Action
- Semantics: 선택 끼니, 추천 근거, 수락 상태
- 이미지에 의미 있는 대체 Label
