## Entry

UI-014 Report 알림 또는 UI-018 오늘 날짜 Summary.

## Route

`/partner/report/:date`를 사용하며 `date`는 ISO `YYYY-MM-DD` 형식이다.

## Exit

가사 요청은 UI-012, Calendar는 UI-018로 이동한다.

## Back Behavior

알림/Calendar 중 실제 진입 화면으로 복귀한다.

## Required Components

### Reuse

- `AppCard`, `AppBanner`, `AppTopBar`, `ResponsivePageContent`
- `ConditionSummaryBanner`, `CategoryBadge`, `GuideTaskCard` read-only, `FamilyParticipationSummary`, 상태 Component
- UI-015 Report Projection

### New

- `PartnerMorningSummary`
- Partner Report Controller/State

## UI Structure

```text
Partner Page
├─ AppTopBar(profile/notification)
└─ ResponsivePageContent
   ├─ PartnerMorningSummary
   ├─ condition / activity summary
   ├─ four guide summaries read-only
   └─ household request / calendar actions
```

## UI State

- Loading
- Ready / Partial shared data
- Empty/no report
- Error/unlinked
- Disabled/unshared detail

## Interaction

- Tap/Keyboard: 요청, Calendar, Notification
- Hover/Focus: Actionable Summary
- Scroll: 전체 Report

## Data

UI-015에서 공유 허용된 날짜/주차/Condition/Activity/Guide/Request Projection만 사용한다.

Data Source: `MockReportService` Partner Projection

Future: `ApiReportService`로 교체. 민감정보 범위를 추정하거나 Backend 생성 Trigger를 구현하지 않는다.

## Responsive

- Mobile-width Web: 단일 Column
- Tablet-width Web/Desktop: 최대 720px, 보조 Summary만 2열

## Accessibility

- Focus: 상태 Summary → Guide → 요청/Calendar
- Keyboard: 모든 Detail Link
- Semantics: 공유 정보, 읽기 전용, 상태를 Text로 전달
