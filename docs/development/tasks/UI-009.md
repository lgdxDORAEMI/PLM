# UI-009 Health Guide

MVP에서 모션 데이터 없이 당일 컨디션을 기준으로 집중 신체 부위와 스트레칭·산책·마사지 가이드를 제공하고 완료를 기록한다.

## Entry

UI-006 Health Guide Summary.

## Route

`/wife/home/health`을 사용한다.

## Exit

콘텐츠 확인/완료 후 현재 화면을 갱신하거나 Back으로 UI-006에 복귀한다.

## Back Behavior

UI-006 Home으로 복귀한다. 제출 중 중복 Pop을 막는다.

## UI State

- Loading
- Ready
- Empty
- Error / Retry
- Completing / Disabled
- Completed

## Interaction

- Tap/Keyboard: 콘텐츠 보기, 완료, 재시도
- Hover/Focus: Activity Card/Action
- Scroll: 집중 부위부터 다른 활동 순서

## Data

컨디션 기반 부위/강도/출처 Label, 활동 종류, 설명, 콘텐츠 참조, 완료 상태만 정의한다.

Data Source: `MockHealthService`

Future: `ApiHealthService`로 교체. 모션/MediaPipe Backend를 연결하지 않고 실제 썸네일이 없으면 임의 이미지를 만들지 않는다.

## Responsive

- Mobile-width Web: 단일 Column
- Tablet-width Web: 최대 560~720px, 짧은 Metric만 2열
- Desktop: Main 흐름 단일 Column

## Accessibility

- Focus: 상태 → 집중 부위 → 활동 → 완료
- Keyboard: Card/완료 Action
- Semantics: 강도와 완료를 Text로 전달
- 건강 문구는 진단이 아닌 추천/참고로 표현
