# UI-008 Meal Adjustment Chat

## Goal

식사 가이드에 한정된 대화로 대체 메뉴를 요청하고 새 추천을 기존 Meal 상태에 적용하는 Loop를 구현한다.

## Entry

UI-007의 재추천 Action.

## Route

`/wife/meal-chat`을 사용한다. Meal Context와 Draft는 URL이 아닌 Feature State로 전달한다.

## Exit

추천 적용 후 UI-007로 결과를 반영하거나 Back으로 기존 Meal에 복귀한다.

## Back Behavior

작성 중 Draft 또는 미적용 추천이 있으면 이탈 확인 후 UI-007로 돌아간다.

## Required Components

### Reuse

- `AppButton`, `AppTextField`, `AppCard`, `AppChip`, `AppBanner`
- `AppTopBar`, `ResponsivePageContent`, 상태 Component
- UI-007 `MealRecommendationCard`의 표시 Model

### New

- `MealChatConversation`, `MealRechoiceCard`
- Chat Message/Conversation State, Mock Conversation Service/Controller

## UI Structure

```text
Page
├─ AppTopBar
└─ ResponsivePageContent
   ├─ current meal context
   ├─ MealChatConversation
   │  ├─ messages
   │  ├─ quick replies <= 3
   │  └─ composer
   └─ MealRechoiceCard
      └─ apply / show another
```

## UI State

- Initial / Composing
- Responding / Loading
- Response Error / Retry
- Recommendation proposed
- Applying / Disabled
- Applied

## Interaction

- Input/Keyboard: 작성, Enter 전송 정책, multiline
- Tap: Quick Reply, 전송, 적용, 다른 메뉴
- Hover/Focus: Action과 Composer
- Scroll: 새 메시지 노출, Focus를 강제로 빼앗지 않음

## Data

식사 Context, 발신자 구분, 메시지 Text/시간, Quick Reply, 대체 Meal 제안과 적용 상태만 정의한다.

Data Source: `MockMealService`의 Conversation 구현

Future: AI ApiService로 교체. 의료 진단 문구와 식사 외 루틴 재조정은 금지하며 Mock 대화를 Widget에 하드코딩하지 않는다.

## Responsive

- Mobile-width Web: Bubble 78%/84%, Composer Safe Area
- Tablet-width Web/Desktop: 최대 720px, 대화 폭 유지

## Accessibility

- Focus: 이전 Context → Message Log → Quick Reply → Composer
- Keyboard: 전송/줄바꿈 규칙 명확화
- Semantics: 새 AI 응답을 Live Region으로 알리되 전체 Log 재낭독 금지
- `AI 추천`과 참고 성격을 Text로 표시
