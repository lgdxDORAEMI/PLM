# UI-015 Wife Daily Report

## Goal

하루 루틴 완료 시 MVP 범위의 실행 결과와 가족 참여를 집계해 저장·조회·공유 가능한 Daily Report UI를 구현한다.

## Entry

UI-006 `하루 루틴 끝내기` 또는 UI-016 날짜 선택.

## Route

`/wife/calendar/report/:date`를 사용하며 `date`는 ISO `YYYY-MM-DD` 형식이다.

## Exit

UI-016 Calendar 또는 공유 결과 Modal.

## Back Behavior

Calendar에서 진입하면 UI-016으로 복귀한다. 하루 종료 직후에는 Report → Calendar 흐름으로 이동한다.

## UI State

- Loading
- In progress / Ready / Historical
- Empty
- Error / Retry
- Saving/Sharing / Disabled
- Saved/Shared

## Interaction

- Tap/Keyboard: 기록 Detail, 저장, 공유, Calendar
- Hover/Focus: actionable Row/Button
- Scroll: Summary부터 세부 기록

## Data

날짜, 임신 주차, MVP Routine 실행/건너뜀, 배우자 요청 상태, 완료 Metric과 공유 상태만 포함한다. 가전 이력과 모션 요약은 제외한다.

Data Source: `MockReportService`가 UI-007/009/010/012 공유 기록을 Projection

Future: `ApiReportService`로 교체. 기존 Backend 모션 `/report/daily`를 제품 Daily Report 계약으로 오인해 직접 연결하지 않는다.

## Responsive

- Mobile-width Web: 단일 Column
- Tablet-width Web/Desktop: 최대 720px, Metric만 Text Scale 허용 시 2~3열

## Accessibility

- Focus: Summary → 기록 → 가족 참여 → Action
- Keyboard: Detail/저장/공유
- Semantics: 수치 의미, 카테고리, 수행/건너뜀/파트너 완료를 Text로 제공
