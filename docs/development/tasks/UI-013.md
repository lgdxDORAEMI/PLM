# UI-013 Partner Profile

## Goal

파트너가 전역 Profile Button에서 별도 Menu 없이 자신의 기본 정보와 아내 연결 상태를 읽기 전용으로 확인하게 한다.

## Entry

모든 Partner 화면의 우측 상단 Profile Button.

## Route

`/partner/profile`을 사용한다.

## Exit

Back으로 실제 진입 Partner 화면에 복귀한다.

## Back Behavior

이전 화면으로 단순 복귀한다. 수정 Draft가 없으므로 이탈 확인은 없다.

## Required Components

### Reuse

- `AppCard`, `AppBanner`, `AppTopBar`, `ResponsivePageContent`, `StatusBadge`, 상태 Component
- UI-001 `ProfileSummary`의 `readOnlyPartner` Variant 또는 공통 표시 Primitive

### New

- Partner Profile read-only Page/State
- 필요 시 ProfileSummary의 Partner Variant만 추가

## UI Structure

```text
Page
├─ AppTopBar(back)
└─ ResponsivePageContent(form)
   ├─ basic profile summary
   └─ wife connection status
```

## UI State

- Loading
- Ready/read-only
- Empty/unlinked
- Error
- Disabled: 모든 Field 편집 불가

## Interaction

- Tap/Keyboard: Back과 Retry만
- Hover/Focus: Back/Retry

## Data

문서가 정의한 파트너 기본 Profile 표시 정보와 연결 상태만 포함하며 새 편집 Field를 추가하지 않는다.

Data Source: UI-001 Profile Mock Service 또는 역할별 Projection

Future: Profile ApiService로 교체. 실제 인증/연결 Backend를 구현하지 않는다.

## Responsive

- Mobile-width Web: 20px, 단일 Column
- Tablet-width Web/Desktop: 중앙 최대 560px

## Accessibility

- Focus: Back → 정보 읽기 → Retry
- Keyboard: Back/Retry
- Semantics: 읽기 전용과 연결 상태 명시
