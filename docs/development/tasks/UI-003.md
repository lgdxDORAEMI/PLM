## Entry

외부 Invite Entry Adapter가 유효성 확인에 필요한 Mock Context를 전달한다.

## Route

내부 진입은 `/invitation-entry?token={token}`을 사용한다. `token` Query 이름은 내부 Adapter 계약으로 고정하되 외부 Domain과 로그인 복귀 URL은 미정이다.

## Exit

연결 성공 후 UI-018 Partner Main. 로그인/설치 필요는 실제 화면을 만들지 않고 안내 상태만 제공한다.

## Back Behavior

외부 진입과 인증 흐름 정책 확정 전 `TBD`. 실패 상태에서 임의 Home으로 보내지 않는다.


- Validating
- Valid

## Interaction

- Tap/Keyboard: 수락, 재시도, 계속
- Hover/Focus: Action
- Transition: 검증 → 연결 → 완료, Reduced Motion 지원

## Data

초대 표시 정보와 상태 enum만 사용한다. 실제 Secret Token을 Fixture나 Log에 넣지 않는다.

Data Source: `MockInvitationService`

Future: 인증/Deep Link 계약 확정 후 Adapter와 ApiService로 교체 예정이다. UI에 Mock JSON을 하드코딩하지 않는다.

- Tablet-width Web/Desktop: 중앙 480px 단일 Panel

- Focus: 상태 안내 → Primary/Retry
