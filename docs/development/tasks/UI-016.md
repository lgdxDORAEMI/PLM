# UI-016 Wife Condition Calendar

## Goal

월별 컨디션 상태를 탐색하고 선택한 날짜의 Daily Report로 이동하는 Wife Calendar를 구현한다.

## Entry

Wife Navigation 또는 UI-015 Daily Report.

## Route

`/wife/calendar`을 사용한다. 날짜 선택 시 `/wife/calendar/report/:date`로 이동해 선택 날짜를 URL에 반영한다.

## Exit

기록 있는 날짜를 선택하면 UI-015 `:date` Report로 이동한다.

## Back Behavior

Wife Shell의 이전 Tab/화면으로 복귀한다. 월 이동은 Browser History를 과도하게 쌓지 않는다.

## Required Components

### Reuse

- `AppIconButton`, `AppCard`, `AppBanner`
- `AppShell`, `AppTopBar`, `ResponsivePageContent`, `MetricCard`, 상태 Component
- UI-015 Report Model/Service

### New

- `ConditionCalendar` Wife Variant

## UI State

- Loading
- Ready / Selected
- Empty month / Empty date
- Error / Retry
- Disabled/unshared date if applicable

## Interaction

- Tap/Keyboard: 이전/다음 달, 날짜 선택, Report 진입
- Hover/Focus: 날짜 Cell
- Transition: 선택일 Summary 갱신

## Data

월, 날짜, 컨디션 Level, 기록 존재 여부, 선택일 Report 참조를 정의한다.

Data Source: `MockReportService` Calendar Projection

Future: `ApiReportService`로 교체. UI에 월 Fixture나 임의 API Query를 넣지 않는다.

## Responsive

- Mobile-width Web: Calendar → Summary Stack, Cell 최소 44px
- Tablet-width Web/Desktop: 최대 720px
- 200% Text: Calendar와 Detail을 분리/Stack하고 Cell 의미 보존

## Accessibility

- Focus: 월 이동 → Grid → Summary
- Keyboard: Arrow로 Grid 탐색, Home/End 정책은 구현 시 문서화
- Semantics: 날짜, 선택, 오늘, 컨디션, 기록 존재 여부
- 상태를 색뿐 아니라 dot/ring/Label로 표현
