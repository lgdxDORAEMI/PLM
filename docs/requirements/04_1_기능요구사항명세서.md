# 기능 요구사항 명세서: ThinQ Pregnancy Life Mode

- 작성 기반: `PRD.md`, `MVP.md`, `유스케이스다이어그램.md`, `유스케이스명세서.md`
- 기능 ID 규칙: `{W|H}-{화면코드}-{일련번호}` — W(Wife, 아내용 앱) / H(Husband, 남편용 앱)
- 우선순위: 상(MVP 필수) / 중(MVP 포함, 범위 축소 또는 조건부) / 하(Phase 2 이후)

## 3. 우선순위 요약

| 우선순위 | 기능 수 | 비고 |
|---|---|---|
| 상 | 20개 | MVP 핵심 루프(프로필→컨디션→AI루틴→실행기록→리포트/캘린더, 남편 리포트·가사요청 흐름) |
| 중 | 6개 | MVP 포함하되 범위를 축소하거나 조건부로 제공 |
| 하 | 7개 | 가전 자동 실행, 홈카메라 모션 모니터링, 전체 루틴 자유 대화, 푸시 인프라 등 Phase 2 |
