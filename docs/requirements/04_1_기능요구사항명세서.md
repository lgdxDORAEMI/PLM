# 기능 요구사항 명세서: ThinQ Pregnancy Life Mode

- 작성 기반: `01_PRD.md`, `01_MVP.md`, `02_유스케이스다이어그램.md`, `03_유스케이스명세서.md`, 화면 설계서(수정본) 반영
- 기능 ID 규칙: `{W|H|B}-{화면코드}-{일련번호}[-{서브번호}]` — W(Wife, 아내용 앱) / H(Husband, 남편용 앱) / B(Both, 아내·남편이 동일 화면·데이터를 공유하는 공통 기능). 팝업·완료 안내처럼 특정 FR의 실행 결과로만 뜨고 독립적으로 진입할 수 없는 오버레이는 별도 화면으로 취급하지 않고, 그 동작을 유발한 FR 번호에 `-1`을 붙여 표기한다(예: FUC-W-HOUSE-003의 전송 완료 팝업 = FUC-W-HOUSE-003-1)
- 우선순위: 상(MVP 필수) / 중(MVP 포함, 범위 축소 또는 조건부) / 하(Phase 2 이후)
- 이번 개정에서 화면 설계서의 화면 단위에 맞춰 프로필(6단계)·식사·수면·가사요청 FR을 세분화했다. 화면 설계서의 화면 ID는 채택하지 않고 기존 ID 규칙을 그대로 유지한다.

## 화면 코드 정의

| 코드 | 화면명 | 사용 앱 |
|---|---|---|
| ENTRY | 진입 분기 (ThinQ 메인 → Pregnancy Life Mode 탭) | 공통(B) |
| PROFILE | 프로필 (아내: 6단계 온보딩 등록 + 이후 수정, 남편: 조회 전용) | 아내·남편 |
| MENU | 전역 프로필 버튼 클릭 시 노출되는 메뉴 목록 | 아내 |

| ACT | 오늘 예정 활동 선택 | 아내 |
| HOME | 홈 화면 (웰컴 카드, 조건부 CTA/가이드 요약, AI 루틴 생성 호출, 오늘의 일정 마치기) | 아내 |
| CALLBACK | AI 엔진 응답 실패 시 폴백 처리 로직 (화면 아님, HOME·MEAL·HEALTH·SLEEP·CHAT 등 AI 엔진을 호출하는 모든 화면에서 공통 사용) | 아내 |
| MEAL | 식사 가이드 | 아내 |

| REQUEST | 가사 요청 카드 | 남편 |

| JOIN | 초대 수락 및 계정 연동 | 남편 |
| SETTING | 설정 (전역 메뉴에서 진입, 상세 항목 미정 Phase 2 플레이스홀더) | 아내 |

> PROFILE 화면과 전역 프로필 버튼은 아내 전용이다. 별도 탭 메뉴가 아니라 **모든 화면 우측 상단의 전역 프로필 버튼**을 통해 어디서든 진입한다. 아내는 최초 가입 시 6단계 온보딩(FUC-W-PROFILE-001~007)을 거치고, 이후에는 MENU의 '프로필 수정'(FUC-W-PROFILE-008)으로 같은 입력 항목을 재수정한다.
> MENU도 아내 전용이다. 전역 프로필 버튼을 누르면 프로필 헤더 요약, 프로필 수정, 남편 연동 행(연동 전: 초대하기 진입 / 연동 후: 연결 안내로 대체), 설정, 하단 약관으로 구성된 목록이 뜬다. 남편은 프로필을 만들지 않으며, 남편 화면에는 전역 프로필 버튼 자체가 없다.
> MOTION(실시간)은 아내와 남편의 진입 경로가 다르다. **아내는 하단 메뉴바의 '실시간' 탭으로만 진입**하지만, **남편은 하단 메뉴바 자체가 없고** 캘린더(FUC-B-CAL-001) 화면의 '실시간 홈캠 신체 정보 보기' 버튼을 통해서만 진입한다. 두 경우 모두 동일한 당일 로그를 공유 조회한다.
> CAL(캘린더)은 아내가 작성한 컨디션·실행 기록을 보여주는 화면 자체가 동일해 공통(B)으로 관리한다. 남편이 조회할 때만 '실시간 홈캠 신체 정보 보기' 버튼이 추가로 노출되는 점만 다르다(아내는 하단 메뉴바에 실시간 탭이 따로 있어 이 버튼이 필요 없음).
> ENTRY(진입 분기)는 ThinQ 메인 화면에서 Pregnancy Life Mode 탭을 선택했을 때 최초 진입인지 이미 가입한 사용자인지에 따라 온보딩 화면(아내: SCR-W-01, 남편: SCR-H-06)과 홈 화면(아내: SCR-W-04 HOME, 남편: SCR-H-02)으로 갈리는 공통 진입점이다.
> HOME(홈 화면)은 웰컴 카드·CTA·가이드 요약·완료 버튼과 함께 그 내용을 만들어내는 AI 엔진 호출까지 하나의 화면(SCR-W-04)에서 처리한다. 별도 화면이나 완료 안내 없이 AI 응답 결과가 반영된 HOME으로 바로 진입한다.
> CALLBACK(AI 엔진 폴백 처리)은 HOME 전용이 아니라 AI 엔진을 호출하는 모든 화면(HOME·MEAL·HEALTH·SLEEP·CHAT)이 공유하는 공통 로직이라 화면 코드와 기능 요구사항을 별도로 둔다.
> **공통(B) 규칙**: ENTRY·MOTION처럼 아내·남편 앱이 동일한 화면·데이터·로직을 그대로 공유하는 경우에만 `B-{화면코드}-{일련번호}` ID를 사용한다. 같은 화면 코드를 쓰더라도 표시 내용이 서로 다른 PROFILE·REPORT·CAL 등은 기존 W/H 구분을 유지한다.
