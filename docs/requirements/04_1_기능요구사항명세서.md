# 기능 요구사항 명세서: ThinQ Pregnancy Life Mode

- 작성 기반: `PRD.md`, `MVP.md`, `유스케이스다이어그램.md`, `유스케이스명세서.md`
- 기능 ID 규칙: `{W|H}-{화면코드}-{일련번호}` — W(Wife, 아내용 앱) / H(Husband, 남편용 앱)
- 우선순위: 상(MVP 필수) / 중(MVP 포함, 범위 축소 또는 조건부) / 하(Phase 2 이후)

---

## 화면 코드 정의

| 코드 | 화면명 | 사용 앱 |
|---|---|---|
| PROFILE | 프로필 (아내: 임신정보 설정/수정, 남편: 조회 전용) | 아내·남편 |
| SETTING | 설정 (플레이스홀더) | 아내 |
| COND | 오늘의 컨디션 체크 | 아내 |
| ACT | 오늘 예정 활동 선택 | 아내 |
| ROUTINE | AI 하루 루틴 홈 | 아내 |
| MEAL | 식사 가이드 | 아내 |
| HOUSE | 가사 가이드 & 가족 분담 | 아내 |
| MOTION | 실시간 탭 (위험 행동 로그, 하단 메뉴바 전용 진입) | 아내·남편 |
| HEALTH | 건강 가이드 | 아내 |
| SLEEP | 수면 가이드 | 아내 |
| CHAT | AI 챗봇 | 아내 |
| RECORD | 루틴 실행 기록(완료 체크, 각 가이드 화면 내 공통) | 아내 |
| REPORT | Daily 리포트 / 오전 컨디션 리포트 | 아내·남편 |
| CAL | 컨디션 캘린더 / 남편 캘린더 | 아내·남편 |
| NOTI | 알림 벨 | 남편 |
| REQUEST | 가사 요청 카드 | 남편 |
| INVITE | 남편 초대하기 (최초 등록 직후 자동 노출 + 전역 메뉴 재진입) | 아내 |
| JOIN | 초대 수락 및 계정 연동 | 남편 |

> PROFILE 화면은 별도 탭 메뉴가 아니라 **모든 화면 우측 상단의 전역 프로필 버튼**을 통해 어디서든 진입한다. 아내는 진입 시 프로필 수정/설정 중 선택하고, 남편은 별도 메뉴 없이 바로 프로필 조회 화면으로 이동한다.
> MOTION(실시간 탭)은 아내·남편 모두 각자 앱의 **하단 메뉴바**에서 동일한 당일 위험 행동 로그를 공유 조회한다(다른 화면의 하위 메뉴가 아님).
