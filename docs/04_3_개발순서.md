# 개발 순서: ThinQ Pregnancy Life Mode

- 작성 기반: `04_1_기능요구사항명세서.md` (우선순위 1~10, 10이 최우선), `01_PRD.md`, `01_MVP.md`, `03_유스케이스명세서.md`, `04_2_비기능요구사항명세서.md`
- 정렬 원칙: 우선순위가 높은 기능부터 개발한다. 단, 기능 설명에 선행 조건이 있는 경우 우선순위가 낮아도 해당 기능 바로 앞에 배치한다.
- 표기: `(우선순위)`, 선행 배치한 기능은 `(우선순위, 선행 대상)`

---

## 1. W-PROFILE-001 임산부 프로필 입력 및 저장 (10)
- 로컬 구현 완료, 커밋 전
- Supabase에 migration SQL 적용
- 테스트 계정으로 저장 확인 후 커밋

## 2. W-COND-001 당일 컨디션 입력 (10)
- 입덧·허리/골반 통증·피로감·수면 상태 입력 척도 확정 (문서 미정)
- 사용자·날짜당 1행, 재입력 시 덮어쓰기 테이블
- 60초 내 완료 UX(NFR-019), 민감정보 분리(NFR-010)

## 3. W-TASK-001 오늘 예정 활동 선택 (5, W-ROUTINE-001 선행)
- 가사 활동 카드 목록 확정
- 날짜별 복수 선택 저장 구조
- 루틴 생성 요청에 포함할 데이터 형식

## 4. W-ROUTINE-001 AI 하루 루틴 생성 요청 (10)
- Claude API 키·크레딧, `anthropic` SDK 의존성
- 입력(프로필·컨디션·주차·전일 활동) 최소 항목(NFR-014)
- 응답 스키마: 식사/가사/건강/수면 4종 가이드

## 5. W-ROUTINE-003 AI 엔진 응답 실패 시 폴백 루틴 제공 (9)
- 기본 템플릿 루틴 문구
- 전일 루틴 재사용용 저장
- 실패 로깅, 폴백 성공률 99.9% 이상(NFR-016)

## 6. W-ROUTINE-002 하루 루틴 4종 가이드 표시 (9)
- 홈 화면 4종 가이드 레이아웃
- 상단 "임신 시기 안내 1줄" 생성 방식
- 응답 대기 UX(p95 10초, NFR-001), "의료 자문 대체 아님" 고지

## 7. W-HOUSE-001 가사 항목 3분류 표시 (8, W-HOUSE-003 선행)
- AI 가사 가이드 응답의 직접수행/가전수행/가족분담 필드
- 분류별 카드 UI
- 가전 수행은 추천 표시까지(MVP)

## 8. W-HOUSE-003 가사 요청 카드 전송 (7, H-REQUEST-001 선행)
- 아내-남편 계정 연동 구조
- 요청 테이블(이유·집안일·보조 정보·상태)
- 알림 생성, 미연동·전송 실패 처리(UC5 E1/E2)

## 9. H-REQUEST-001 가사 요청 카드 확인 (10)
- 남편 로그인·역할 구분
- 연동된 아내 요청만 조회되도록 권한 설정
- 카드 UI(이유·집안일·보조 정보)

## 10. H-REQUEST-002 요청 상태 전환 — 확인 (8, H-REQUEST-003 선행)
- 상태값 정의: 요청됨 → 확인됨 → 완료
- 확인 API, 아내 화면 반영
- 연동된 남편만 변경 가능하도록 권한 설정

## 11. H-REQUEST-003 요청 상태 전환 — 완료 (10)
- 완료 상태 Household DB 저장
- 아내 화면·캘린더·리포트 반영 경로
- 저장 오류 시 재시도 안내(UC9 E2)

## 12. W-MEAL-001 식사 가이드 메뉴 추천 표시 (9)
- 프로필에 알레르기·혈당 항목 추가 (현재 프로필에 없음)
- 주차별 부족 영양소, 입덧·소화 상태 입력 연결
- 응답 필드: 메뉴·추천 이유·영양 목적

## 13. W-COND-002 컨디션 저장 시 남편 리포트 트리거 (7, H-REPORT-001 선행)
- 컨디션 저장 직후 실행되는 트리거
- 남편 미연동 시 트리거 생략
- 트리거 실패해도 컨디션 저장은 성공 처리

## 14. H-REPORT-001 오전 컨디션 리포트 자동 생성 및 표시 (9)
- 리포트 내용: 임신 주수·컨디션·예정 활동·4대 가이드 요약
- 남편 공유 항목 아내 동의 범위(NFR-013)
- 알림 실패 시에도 캘린더 조회 가능(UC8 E2)

## 15. W-RECORD-001 직접 행동 완료 체크 (8)
- 실행 기록 테이블(날짜·항목·완료 여부)
- 완료 체크·취소(UC6 A1)
- 식사·건강·수면 카드 공통 체크 컴포넌트

## 16. W-CHAT-001 자연어 기반 식사 가이드 재조정 (8)
- 챗봇 UI, 대화 맥락(프로필·주차·컨디션)
- 식사 한정 재조정 프롬프트
- 의료 진단 요청 차단 안내(UC4 E2), 응답 p95 8초(NFR-004)

## 17. W-MEAL-002 챗봇 기반 메뉴 재추천 (8)
- 재추천 결과를 식사 가이드에 반영
- 수락 시 루틴 저장(UC4)
- 재요청 흐름(UC4 A1)

## 18. W-RECORD-002 남편 요청 완료 상태 반영 (7)
- H-REQUEST-003 완료 상태 수신
- 아내 실행 기록 자동 반영
- 요청 항목과 실행 기록 연결 키

## 19. W-HEALTH-002 활동 완료 체크 (7)
- 스트레칭·산책 활동 카드
- W-RECORD-001 공통 기록 재사용
- 스트레칭 영상 콘텐츠 출처

## 20. W-SLEEP-001 수면 루틴 및 환경 설정 제안 (7)
- 수면 기록 입력원(컨디션의 수면 상태)
- 응답 필드: 온도·조명·공기환경 제안값
- 가전 실행 없이 제안까지(MVP)

## 21. H-CAL-001 날짜별 아내 생활 기록 조회 (7)
- 날짜별 조회 API(리포트·컨디션·루틴·수행 결과·분담)
- 아내 동의 항목만 노출(NFR-013)
- 데이터 없는 날짜 표시(UC10 A1)

## 22. W-PROFILE-002 프로필 수정 (6)
- `PUT /api/v1/profile/me`, 저장값이 채워진 폼
- 수정 시 임신 주수 즉시 재계산
- 설계 완료, 승인 대기

## 23. W-REPORT-001 Daily 리포트 생성 (6)
- "하루 루틴 끝내기" 트리거
- 실행 루틴·시청 콘텐츠 이력 집계 (가전 작동 이력은 MVP 제외)
- 리포트 저장 구조

## 24. W-CAL-001 컨디션 캘린더 날짜별 조회 (6)
- 캘린더 UI
- 날짜별 컨디션·루틴·실행 여부·분담 조회 API
- 기록 없는 날짜 처리(UC7 A1)

## 25. W-HEALTH-001 부위 우선순위 기반 콘텐츠 추천 (5)
- 컨디션 입력 기반 부위 판단(MVP 단순화)
- 부위별 스트레칭·마사지 콘텐츠
- 다른 부위는 화면 하단 선택 조회

## 26. H-NOTI-001 통합 알림 목록 표시 (5)
- 알림 테이블(리포트 도착·요청·미확인·미완료)
- 앱 내 목록·뱃지까지 (푸시 제외)
- 알림 클릭 시 해당 화면 이동

## 27. W-MEAL-003 메뉴 수락/거절 이력 기록 (4)
- 수락/거절 이력 테이블
- AI 추천 요청에 이력 포함
- 이력 항목 최소화(NFR-014)

## 28. W-MEAL-004 메뉴 카드 남편 공유 (4)
- 공유 메뉴 카드 데이터
- 남편 화면에서 가사 요청 카드와 구분되는 위치
- 공유 동의 범위(NFR-013)

## 29. W-HOUSE-002 가전 수행 항목 실행 요청 (3)
- ThinQ 디바이스 API 접근 권한
- 기기 소유권 검증(NFR-006)
- 오프라인·권한 오류 처리(UC12 E1~E3)

## 30. W-CHAT-002 전체 루틴 자유 대화형 재조정 (3)
- 가사·건강·수면 의도 분류 설계
- 영역별 재조정 프롬프트
- 설정창 직접 조정과 겹칠 때의 우선 규칙

## 31. W-SLEEP-002 연결 가전 실행(수면 환경) (2)
- ThinQ API(에어컨·조명·공기청정기)
- 기기 소유권 검증(NFR-006)
- 실행 결과 기록(UC12)

## 32. W-MOTION-001 홈카메라 실시간 활동 로그 조회 (1)
- 홈카메라 하드웨어, 기존 `backend/app/services/movement` 모듈 연동
- 촬영 동의 철회 1분 내 수집 중단(NFR-012), 원본 영상 7일 이내 보관(NFR-011)
- "의료 진단 아님" 고지 문구

## 33. W-REPORT-002 모션 데이터 기반 관절 부담 요약 (1)
- W-MOTION-001 누적 활동 데이터
- 관절 부담 기준 확정 (`docs/movement` 구현계획서 기준)
- Daily 리포트 요약 섹션
