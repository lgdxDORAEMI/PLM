# 서비스 흐름도

`docs/requirements/**`를 기준으로 사용자 입장별 서비스 흐름을 Mermaid(`flowchart`)로 정리한 문서다. 요구사항과 흐름도가 다르면 요구사항 문서가 우선한다.

- `아내/`: 아내(임산부)가 PLM 앱에서 겪는 흐름
- `남편/`: 남편이 PLM 앱에서 겪는 흐름

두 사용자가 함께 쓰는 기능(가사 요청, 실시간, 캘린더, 오전 리포트)은 각자의 입장에서 따로 그렸다. 파일 끝의 `다음 흐름:` 노드가 같은 폴더 안의 다음 흐름도를 가리키고, 상대방 폴더로 넘어가는 경우 `아내/…`, `남편/…`처럼 폴더를 붙였다.

## 아내

| 파일 | 내용 | 주요 기능 ID |
|---|---|---|
| `아내/00_진입분기.mmd` | ThinQ에서 PLM 진입 → 프로필 등록 여부로 온보딩/홈 분기 | FUC-B-ENTRY-001, FUC-W-PROFILE-009 |
| `아내/01_프로필등록및메뉴.mmd` | 프로필 6단계 등록·확인·수정, 메뉴, 설정(글자 크기), 남편 초대(ThinQ 초대 알림) | FUC-W-PROFILE-001~009, FUC-W-MENU-001, FUC-W-SETTING-001, FUC-W-INVITE-001/002 |
| `아내/02_AI하루루틴생성.mmd` | 컨디션 체크 → 집안일 선택 → AI 루틴 생성·실패 폴백 → 입력값 수정/같은 날 새 루틴 | FUC-W-HOME-001/002, FUC-W-COND-001~004, FUC-W-TASK-001/002, FUC-W-CALLBACK-001 |
| `아내/03_식사가이드및챗봇.mmd` | 끼니 선택 → 메뉴 상세(주차별 고정 콘텐츠) → 챗봇 재조정 | FUC-W-MEAL-001~005, FUC-W-CHAT-001/003/004 |
| `아내/04_가사가이드및가족분담.mmd` | 가사 3분류 → '가족과 나누기' 항목만 남편에게 요청 → 진행 상태 조회 | FUC-W-HOUSE-001~003-1, FUC-W-RECORD-002 |
| `아내/05_건강가이드.mmd` | 부위 우선순위 활동 추천 → 활동 완료 체크 | FUC-W-HEALTH-001/002 |
| `아내/06_수면가이드.mmd` | 수면 환경 설정 바텀시트 → '수면 루틴 시작하기'(가전 실행 성공 시 실행 기록) | FUC-W-SLEEP-001/001-1/002, FUC-W-RECORD-001 |
| `아내/07_실시간탭.mmd` | 하단 '실시간' 탭 — 홈캠 당일 감지 로그 조회 | FUC-B-MOTION-001 |
| `아내/08_루틴실행기록및리포트.mmd` | 실행 기록 → Daily 리포트 생성·확정 → 캘린더 조회 | FUC-W-RECORD-001, FUC-W-REPORT-001~002, FUC-B-CAL-001 |

## 남편

| 파일 | 내용 | 주요 기능 ID |
|---|---|---|
| `남편/00_진입분기및초대수락.mmd` | ThinQ 초대 알림 수락·계정 연동 → PLM 진입 분기(미연동 시 '초대 필요' 안내) | FUC-H-INVITE-001, FUC-B-ENTRY-001 |
| `남편/01_캘린더.mmd` | 남편 홈 캘린더 — 날짜별 기록 조회, 알림·실시간·메뉴 진입 | FUC-B-CAL-001, FUC-H-REPORT-001 |
| `남편/02_오전리포트및알림.mmd` | 알림 3종(오전 리포트·가사 요청·루틴 변경) 수신·확인 | FUC-H-REPORT-001, FUC-H-NOTI-001/002 |
| `남편/03_가사요청처리.mmd` | 요청 카드 확인 → 확인 → 완료(거절 없음) → 결과 안내 | FUC-H-REQUEST-001~003 |
| `남편/04_실시간조회.mmd` | 캘린더(오늘 날짜) 버튼으로 아내와 같은 실시간 화면 조회 | FUC-B-MOTION-001 |
| `남편/05_메뉴설정.mmd` | 전역 프로필 버튼(≡) → 메뉴에서 글자 크기 조절 | FUC-H-MENU-001 |

## 표기 규칙

| 모양·색 | 의미 |
|---|---|
| 둥근 사각형(파랑) | 사용자 행동 |
| 사각형(회색) | 시스템 처리 |
| 마름모(노랑) | 분기 |
| 둥근 사각형(초록) | 시작·종료·다음 흐름 |
| 점선 테두리(빨강) | 외부 시스템(ThinQ, AI 엔진, 홈카메라, 가전) |
| 점선 화살표 | 대안 경로, 비동기 반영, Phase 2 경로 |
