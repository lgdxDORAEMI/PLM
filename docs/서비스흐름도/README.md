# 서비스 흐름도

아내와 남편의 사용자 흐름을 Mermaid 파일로 정리한 폴더입니다. 이 도식은 제품 요구사항을 이해하기 위한 자료이며, 현재 앱 동작과 API 구현 여부는 코드 및 [API 문서](../api.md)를 기준으로 확인합니다.

## 아내 흐름

| 파일 | 주제 |
| --- | --- |
| [00 진입](아내/00_진입분기.mmd) | 최초 진입과 프로필 분기 |
| [01 프로필·메뉴](아내/01_프로필등록및메뉴.mmd) | 프로필, 가족 초대, 메뉴 |
| [02 AI 루틴](아내/02_AI하루루틴생성.mmd) | 컨디션, 할 일, 루틴 생성 |
| [03 식사·챗봇](아내/03_식사가이드및챗봇.mmd) | 식사 가이드와 대화 |
| [04 가사](아내/04_가사가이드및가족분담.mmd) | 가사 항목과 가족 분담 |
| [05 건강](아내/05_건강가이드.mmd) | 건강 활동 |
| [06 수면](아내/06_수면가이드.mmd) | 수면 가이드 |
| [07 실시간](아내/07_실시간탭.mmd) | 모션 감지 조회 |
| [08 기록·리포트](아내/08_루틴실행기록및리포트.mmd) | 실행 기록, 리포트, 캘린더 |

## 남편 흐름

| 파일 | 주제 |
| --- | --- |
| [00 진입·수락](남편/00_진입분기및초대수락.mmd) | 초대와 계정 연결 |
| [01 캘린더](남편/01_캘린더.mmd) | 날짜별 공유 기록 |
| [02 리포트·알림](남편/02_오전리포트및알림.mmd) | 오전 리포트와 알림 |
| [03 가사 요청](남편/03_가사요청처리.mmd) | 항목별 확인·완료 |
| [04 실시간](남편/04_실시간조회.mmd) | 오늘 모션 감지 조회 |
| [05 메뉴](남편/05_메뉴설정.mmd) | 메뉴와 설정 |

폴더 바로 아래의 `00_*.mmd`~`10_*.mmd`는 과거 경로에서 참조하는 이전 판입니다. 현재 흐름을 볼 때는 `아내/`와 `남편/` 파일을 우선합니다. 도식의 ThinQ 초대 알림이나 가전 실행 표기는 실제 제품 연동 범위와 다를 수 있습니다.
